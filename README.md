# Azimuth Consumables

A standalone consumable bar for World of Warcraft Forever. Use bag consumables, track active effects and temporary weapon enchants, and see which effects are missing.

## Install

Download [AzimuthConsumables.zip](releases/AzimuthConsumables.zip) and extract it into your game's `Interface/AddOns` directory. Restart the game and enable **Azimuth Consumables**.

See the [addon documentation](addon/AzimuthConsumables/README.md) for controls, effect matching and testing instructions. Azimuth Consumables is licensed under [GPL-3.0-only](addon/AzimuthConsumables/LICENSE).
